## Contributing

Know a great terminal tool that's missing? Submit it through the site — no need to edit this file:

1. Open **[cli.masoko.net/submit](https://cli.masoko.net/submit)** and sign in with GitHub.
2. Fill in the tool's details — a pull request to this repository is opened automatically.
3. Once merged, the site and this README update themselves.

You can also suggest edits to existing listings straight from each tool's page on the site.

> Everything between the markers above is auto-generated from the tool files in
