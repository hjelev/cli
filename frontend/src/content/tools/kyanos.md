description: >-
  Kyanos is an eBPF-powered network analysis and troubleshooting tool designed
  to inspect L7 traffic (such as HTTP, Redis, MySQL, and Kafka).


  It tracks and visualizes the exact time packets spend at the kernel level
  across network layers to isolate performance bottlenecks.


  It provides advanced filters, automatic SSL decryption, and metrics
  aggregation to help diagnose slow requests efficiently from a single binary.
