description: >-
  YYLO is a command-line orchestrator for coding agents, repeatable workflows,
  and receipt-backed repository changes. It is for developers who want a quick
  agent loop and for project operators who need typed task, validation, merge,
  and release-readiness boundaries.

  A live terminal mode (`ypl`) runs an interactive agent session where tool
  calls, streamed output, and the status bar render in the terminal, and each
  run ends with an execution summary of iterations, tool calls, cost, and
  session ids.

  Sister projects YYLO Ledger (a Git-native Record/task store) and YYLO
  Benchmark (an evaluation/evidence package) integrate through `yy ledger` and
  `yy benchmark`.
