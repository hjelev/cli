short_description: A (TUI/CLI) markdown navigator with tree-based structural navigation.
description: >-
  treemd is a command-line tool that renders Markdown files and directory
  structures into visual, tree-like hierarchy views directly in the terminal.


  It parses headings, links, and document structure to output clean ASCII or
  Unicode tree diagrams representing document flow or file organization.


  It is ideal for quickly summarizing project documentation, README files, and
  multi-file Markdown repositories from the shell.
