  lazyssh is a terminal-based, interactive SSH manager written in Go, inspired
  by tools like lazydocker and k9s.


  It provides a keyboard-driven UI to easily manage, sort, search, and connect
  to servers directly from your ~/.ssh/config file.


  It supports advanced SSH features like port forwarding, proxy settings,
  authentication configurations, and automated configuration backups.
