description: >-
  meli is a modern, modal terminal email client written in Rust for Linux,
  macOS, and BSD systems.   

  It supports multiple concurrent accounts and diverse backends, including IMAP,
  JMAP, notmuch, Maildir, mbox, and NNTP.   

  It features a Vim-inspired keybinding scheme, multi-threaded asynchronous
  operations, built-in contact management, and SQLite-backed search indexing.
