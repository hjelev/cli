description: >-
  git-cliff is a highly customizable changelog generator written in Rust that
  uses conventional commits and flexible regular expressions to parse Git
  history.


  It allows you to craft structured, professional release notes from templates,
  automatically grouping changes by type, breaking changes, and contributor
  authors.


  Seamlessly integrating into CI/CD pipelines, release scripts, and local
  terminal workflows, it automates the entire changelog creation process for
  modern open-source and enterprise projects.
