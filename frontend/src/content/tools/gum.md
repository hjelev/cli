  pipelines interactive and visually polished.  

  It provides a rich collection of building blocks—such as inputs, fuzzy
  filters, checkboxes, choosers, file pickers, and formatted styles—without
  requiring Go programming.

  gorgeous interactive command-line UIs and prompts.
